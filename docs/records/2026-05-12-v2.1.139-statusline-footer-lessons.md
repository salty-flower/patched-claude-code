# v2.1.139 Statusline Footer Lessons

## Failure Split

| Failure | Cause | Fix |
| --- | --- | --- |
| Shift+Enter config crash | 2.1.139 minified text/render symbols drifted from older locators. | Add 2.1.139-specific footer render locators. |
| Footer-only `statusLine` crash | `--hide-builtin-footer` can create `settings.statusLine` without `command`; 2.1.139 telemetry read `command.length`. | Keep upstream presence check; make command-length telemetry reads optional. |
| Custom status line disappeared | Schema patch appended `v.boolean()`/`v.array()` into a 2.1.139 scope whose schema symbol is `y`. | Split schema patch by `applies_to`; use the local schema symbol for each target range. |
| Sandboxed status line blank | Machine-state sandbox hook subprocess reports `term size` as `0x0`; statusline script renders a zero-width line. | Fall back to `$env.COLUMNS`, then `80`, in the statusline script. |

## Bump Rules

| Check | Required signal |
| --- | --- |
| Schema patches | Rendered bundle uses the same minified schema symbol as the surrounding object. |
| Presence predicates | Do not narrow upstream display gates to avoid a crash; patch the narrower unsafe read instead. |
| Footer-only settings | Run with `--hide-builtin-footer` and with a real `statusLine.command`. Both paths must work. |
| Debug logs | No settings parse errors before UI startup; custom statusline should emit mount or command logs when debug is enabled. |

## Diagnostic Pattern

- No `StatusLine` mount logs + no command logs: settings likely absent or rejected before UI render.
- Command exits 0 with empty output in `claude` but not `claude-raw`: check hook subprocess terminal width before changing Claude bundle patches.
- `TypeError` during `parseSettingsFile` or `m8()` startup path: inspect patched schema first.
- Footer-only crash in `StatusLine`: search for non-optional `statusLine.command` reads before changing `statusLineShouldDisplay`.

## Version Delta

| Surface | 2.1.138 | 2.1.139 |
| --- | --- | --- |
| StatusLine hook spawn | `spawn(..., { shell: true, windowsHide: true })` | `spawn(..., { shell: true, detached: true, windowsHide: true })` |
| Machine-state sandbox effect | Nu `term size` resolves a usable width. | Detached hook subprocess reports `term size` as `0x0`. |
| Script requirement | `term size` alone works. | Must prefer positive `term size`, else `$env.COLUMNS`, else `80`. |
