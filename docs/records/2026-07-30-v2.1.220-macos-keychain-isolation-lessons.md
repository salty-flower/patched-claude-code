# v2.1.220 macOS Keychain Isolation Lessons

## Credential Source Priority

| Process mode | Authorized source | Forbidden fallback |
| --- | --- | --- |
| Host-managed or bare | None | Explicit Keychain, materialized plaintext, default storage |
| `CLAUDE_CODE_KEYCHAIN_PATH` set | Selected Keychain only | Materialized plaintext, login Keychain |
| Materialized plugin-eval child | Temporary plaintext only | Selected or login Keychain |
| Neither set | Upstream default | None |

> Host guard > public Keychain selection > internal materialized marker > upstream default.

The public variable is an authority boundary.
An inherited internal marker must never override it.
See the supported interface and operator prerequisites in
[`../guides/macOS-Keychain-Isolation.md`](../guides/macOS-Keychain-Isolation.md).

## Failure Map

| Failure | Missed boundary | Required control |
| --- | --- | --- |
| Cross-process lost update or stale cache | Replacing the storage factory bypassed upstream `.storage-write`, cache generation, and in-flight read coordination. | Preserve upstream mutation coordination around the selected storage backend. |
| Raw bundle read the login Keychain | Missing preload bridge fell back to upstream storage. | Explicit selection without the bridge must terminate before credential access. |
| Legacy API key escaped isolation | OAuth secure storage and legacy Keychain commands are independent credential paths. | Audit lookup, save, refresh, invalidation, and deletion for both formats. |
| `security -i` wrote to the login Keychain | The Keychain path followed the command-terminating newline. | Serialize the path before the single terminating newline; test the exact stdin bytes. |
| Unicode path truncation | Interactive input limit used JavaScript character count. | Enforce the limit with UTF-8 byte length. |
| Resume loaded stale plaintext credentials | Session restoration had independent `.credentials.json` and login-Keychain reads. | Route every resume source through the same authority decision. |
| Plugin eval copied the wrong account | Plaintext copy preceded selected-Keychain materialization. | Materialize from the selected source; do not copy caller plaintext first. |
| Plugin eval child rejected explicit selection | Child inherited the public variable without the preload bridge. | Remove the public variable only after materializing credentials into an internal fail-closed mode. |
| Internal marker overrode public selection | Marker checks preceded public-variable checks. | Apply the priority table at every OAuth and legacy entry point. |
| Materialized child touched the login Keychain | Legacy mutation and doctor probe remained reachable. | Reject legacy writes/deletes and disable Keychain probes in materialized mode. |

## Patch Rules

- **Single authority decision:** reads, writes, refreshes, invalidations, deletes, session resume, plugin eval, and diagnostics.
- **No silent fallback:** invalid path, inaccessible Keychain, absent bridge, or unsupported child mode must fail closed.
- **Atomicity preservation:** backend selection must not replace upstream file locking, generation tracking, or stale-read suppression.
- **Central serialization:** one `security -i` encoder; structured non-secret arguments elsewhere.
- **Secret handling:** credential blobs through stdin only; no token logging, copying between Keychains, or subprocess arguments.
- **Auxiliary operations:** doctor probes and cleanup commands obey the same selected source.

## Regression Signals

| Case | Required assertion |
| --- | --- |
| Explicit OAuth and legacy operations | Selected Keychain changes; default sentinel remains byte-for-byte unchanged. |
| Public variable plus internal marker | Public selection wins for OAuth and synchronous/asynchronous legacy lookup. |
| Materialized mode | Plaintext reads work; legacy mutation and doctor cannot access any Keychain. |
| Invalid, relative, missing, or locked path | Actionable error; no default read or write. |
| Spaces, quotes, backslashes, Unicode, CR/LF/NUL | Valid paths round-trip; forbidden characters reject before spawning `security`. |
| Interactive command input | Keychain argument precedes exactly one terminating newline; UTF-8 byte limit enforced. |
| Plugin eval | Launch the real child with a local grader and stub server; helper-only tests are insufficient. |
| Cross-process mutation | Concurrent processes preserve upstream lock and cache-generation semantics. |
| Default mode | Unset public variable retains upstream login-Keychain behavior. |
