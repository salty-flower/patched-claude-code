### Silent no-op carried in from 2.1.268

`teammate-in-process-effort-definition` injects
`...s.effort!==void 0&&{effort:s.effort}`, written at 2.1.263 when the runner
parameter was `s`. From 2.1.268 the parameter is `n` and `s` is the destructured
`taskId`, so the injected spread has evaluated to nothing in every bundle since —
`just verify` proves a locator still matches, never that the injected code still
refers to what its author meant. The 2.1.273 variant uses `n` and is capped to
`<2.1.274`. The shipped 2.1.268 bundle is left as released; no backport.

### Served tool-description text

2.1.273 introduces a GrowthBook string, `tengu_lucky_cerf_text`, that replaces
the Agent tool's entire compiled delegation-cost instruction block — text sent
with every request. It is the only pinned key in the graph that is a free-form
string rather than a boolean, and the only one without a local override.
`tengu_lucky_cerf` (an array) gates whether that text is used.

Both now read through `CLAUDE_CODE_ALLOW_SERVED_TOOL_TEXT`, using the upstream
truthy helper already imported into the defining chunks.
Unset, the bundle uses its compiled local text and does not read either served value.

### Stale assertions that `verify-patches` cannot see

`agent-teammate-effort` and `agent-effort-resolver-priority` applied correctly
but failed their static assertions: both pinned the result of a *dynamic* AST
capture as a literal. The assertions now anchor only on repo-owned identifiers.
`verify-patches` is locator-only and does not evaluate static assertions, so this
class surfaces only in the rendered patch run.

## Bun.ant Blocker and Compatibility Layer

2.1.273's Ink renderer calls `Bun.ant.CellSegmenter` on every frame. That API
exists only in Anthropic's private bun fork (`Bun-Version: 1.4.3`; public bun's
newest is 1.4.2), so the rendered bundle could not start its TUI on any
obtainable runtime. Of the 18 `Bun.ant` keys, the graph calls five; the other
four are wrapped in `try/catch` and degrade, so **only `CellSegmenter` needed
implementing**.

- Contract sampled from the live fork and frozen in
  [the CellSegmenter contract](2026-09-17-bun-ant-cell-segmenter-contract.md).
- Implementation: `runtime/bun-ant-cell-segmenter.ts`, original code, preloaded
  by the launcher beside `runtime/system-prompt-overrides.ts`.
- Acceptance: `tools/test/bun-ant-cell-segmenter.test.ts` replays a captured
  fixture — 48 corpus samples, 20 focused segment regressions, 30 capacity
  cases, six SGR table rows, 28 `paint` cases, and eight paint/`setCell`
  regressions. The fixture binds the 2.1.273 Linux binary SHA-256 and
  repository-owned capture tool. Green.
- Broader differential probes match exactly across 552 SGR cases, 256 ESC-byte
  cases, four C1 cases, 12 reordered-text cases, 486 paint position/screen
  cases, two wide-overlap cases, four tab cases, and all 676 ordered
  regional-indicator pairs on fresh instances.
- Method: [Inspecting the Upstream Bun Runtime](../guides/Inspecting-Upstream-Bun-Runtime.md).

The compatibility layer requires the host's `Intl.Segmenter` and
`Bun.stringWidth`; it fails closed if either primitive is absent rather than
guessing Unicode behavior.
It normalizes the fork's observed Unicode 16 Extended_Pictographic additions
and unsupported emoji-modifier behavior.
A shared-instance 6,823-signature cluster probe retains 56 regional-indicator
differences only after thousands of distinct graphemes have populated the
instance table; fresh instances match all 676 ordered pairs.
The unresolved boundary is long-lived table saturation/index behavior, not
ordinary regional-indicator pair segmentation.

## New Gate: Injected-Symbol Analysis

`tools/test/patch-transform-symbols.test.ts` fails when a code-emitting literal,
regex, substring, or AST transform active at the target injects a bare minified
identifier that is neither a declared `%%CAPTURE:%%`, a repo-owned name, a JS
builtin, nor declared by the snippet — unless its range excludes the next patch
release.
Names copied from a locator or substring `find` are still direct upstream names,
and replacement backreferences are rejected rather than treated as captures.

Falsified before landing: restoring the open range on the teammate entry makes
it fail with the entry name and the offending identifier.
It also surfaced two pre-existing context-window offenders, which now capture
the matched function parameter; four per-model endpoint replacements now stop
before `2.1.274`; and the teammate process flag now captures its model,
command-buffer, and formatter bindings instead of resurrecting regex groups.
