# 2.1.281 AGENTS Hook Runtime Obligation Proposal

## Invariant

| Field | Proposed value |
| --- | --- |
| Family / invariant | `agent-memory-discovery/agents-md-native-hook-load` |
| Introduced | `2.1.281` |
| Platforms | Darwin arm64 and Linux x64 |
| Evidence | `real-os-runtime` |
| Oracle | `agent-memory-discovery/agents-md-native-hook-load` |
| Candidate patch entries | `agents-md-native-hook-host-path-darwin`, `agents-md-native-hook-host-path-linux` |

For each platform, the packaged Bun disk graph must register the built-in
`agents-md` hook and include a unique `AGENTS.md` sentinel in the prompt sent to
a local API stub.

The four existing AGENTS discovery retirements and
`memory-file-realpath-overlap-dedup` remain unchanged.
This invariant covers hook registration and prompt loading; it does not assert
realpath-overlap deduplication.
