## Verification

**Release status: blocked.** The current disk-backed Bun execution of
`graph.patched/` cannot load `builtin:agents-md/hooks/register.ts`.
The bundle uses this synthetic key for standalone hook scanning, while
ordinary Bun resolves it as a missing disk path under `graph.patched/`.
The hook registration module and AGENTS loader are absent from this execution
path, so it cannot validate AGENTS discovery or deduplication.
A native runtime or bridge that loads this module is required before release.
Forcing standalone mode alone has not been shown to resolve the packaging gap.
