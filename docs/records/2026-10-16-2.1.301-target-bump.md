The graph extraction policy now relocates standalone plugin worker URLs as well as module imports.

## Privacy carryover repair

The free-form `tengu_lucky_cerf_text` override existed in 2.1.296 but its previous patch range ended before that target.
The 2.1.301 variants restore its existing `CLAUDE_CODE_ALLOW_SERVED_TOOL_TEXT` opt-in lineage alongside the served web-search and tool-list gates.
Without the explicit local opt-in, the compiled Agent description remains in use and the served string is not consulted.
This is a recovered carryover gap rather than a new 2.1.301 upstream behavior.
Other privacy variants retain explicit assistant-response logging admission, disable raw request/response body OTel, neutralize project-thread author labels, and keep local prompt ablation telemetry unreachable.
