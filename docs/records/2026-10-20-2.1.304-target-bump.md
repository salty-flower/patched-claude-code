## Defects caught before acceptance

- Full-graph verification caught an AGENTS hook locator also matching the new chart plugin. Narrowed the selector; expected match count remains one.
- Runtime tests caught a symbol rename corrupting the Keychain bridge protocol string from `.v1` to `.uB`. Restored seven lookups; retained native `uB` function calls. Added fixed-ABI assertions; real Darwin Keychain suite passed 14 tests / 139 assertions.
- Migrated platform-split ablation selection, native effort-command prepend tests, and platform-specific live-thinking subscriptions without relaxing runtime behavior.
- Independent literal audit covered 298 predecessor/successor entry-platform pairs plus two new imports; no further protocol/event/environment string corruption found. Forty-nine fragments required lexical rather than full-AST comparison.

## Privacy and embedded-resource boundaries

- Prompt/telemetry/host audits reuse one shared two-platform dossier. No additional anti-trace patch required within the reviewed delta; existing protections remain required.
- Date, directory, email/project and scheduling context remain within previously accepted retirement boundaries; not a metadata-free claim.
- Chart creation stores host timezone and generation time in local history. The inherited MCP API mapper removes text-block `_meta` before request assembly. Pure-function evidence confirms non-mutating stripping; explicit `zone: local` still affects requested chart semantics.
- GrowthBook isolated lookup retains privacy admission, disables exposure logging and uses a random cache partition; no new telemetry destination identified in the reviewed URL delta.
- Built-in resource inventory: 376 → 366; each platform removes two whiteboard prompt/template/script triples and adds one secure-deployment reference. No new script/template payload. Both platform content-hash multisets match. Inventory completeness remains partial despite no reported gaps.
