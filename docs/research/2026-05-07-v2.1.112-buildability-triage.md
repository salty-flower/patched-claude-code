| `src/*` internal imports | Use `reconstructed/v2.1.112/tsconfig.json` path alias | `bun --check` advances past `src/bootstrap/state.js` and `src/entrypoints/agentSdkTypes.js` when the alias is present. |
| Package boundary | Keep a private `reconstructed/v2.1.112/package.json` plus `bun.lock` | Public packages are needed for targeted source-checks; the lockfile pins the resolver state. Private `@ant/*` packages remain unavailable. |
| `color-diff-napi` | Use local TS port, not npm | Public npm has only reserved `color-diff-napi@0.0.1` with no exports; `src/native-ts/color-diff/index.ts` provides the expected `ColorDiff`, `ColorFile`, and `getSyntaxTheme` API. |
| Claude in Chrome package | Document as private boundary | `@ant/claude-for-chrome-mcp` returns 404 from the public npm registry and is imported only by `src/utils/claudeInChrome/*`. Do not add a behavior shim unless the package source or a local bundle implementation is recovered. |
| Source rewrites | Do not mass-convert | Current scan finds 1,067 `src/*` import statements across 319 files. Manual conversion would create broad churn without addressing missing extracted files. |
| `node_modules/src` shim | Do not commit | A temporary symlink also advances resolution, but committing `node_modules` state would obscure the source contract. |
| Package self-reference | Do not use | Temporary `package.json` with `name: "src"` did not resolve `.js` specifiers to local `.ts` files under Bun. |
