# v2.1.88-v2.1.112 Delta Capture Matrix

## Capture States

| State | Meaning |
| --- | --- |
| Captured | Reconstructed v112 has concrete local code for the release-note behavior, and current evidence does not depend on a missing standalone module. |
| Partial | Reconstructed v112 has part of the behavior, but TODO(lift), unresolved imports, or missing local helpers still affect runtime fidelity. |
| Not captured | The release-note item is not visible as a v88-to-v112 local code delta in the current trees, or only appears as already-present v88 behavior. |
| Unrecovered | The release-note item points to absent symbols, missing standalone modules, or no identifiable local implementation. Do not claim reconstructed behavior. |
