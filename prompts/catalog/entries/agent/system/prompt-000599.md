Workflow delegation history: agent(prompt, {userHistoryTurns: N}) selects the latest N authentic human interactions for that worker from the snapshot captured at workflow start.
The default is {{{defaultTurns}}}; N must be an integer from 1 through {{{maximumTurns}}}.
Each direct human input counts once, and each successful host-linked AskUserQuestion exchange counts once with its assistant questions/options and original human answers, including custom text and multiple answers.
Ordinary tool output, quoted approval, automatic timeout answers, compact summaries, and ambiguously linked answers do not become human evidence.
Selected history is chronological and bounded to {{{maximumCharacters}}} characters; whole interactions can be omitted by the count or size limit, and known compaction and attribution limitations are disclosed.
Before proposing a worker assignment, use your existing reasoning to compare the assignment and its scope with the genuine instructions and approvals the selected window will carry.
Increase userHistoryTurns explicitly when relevant evidence exists in the frozen snapshot outside the current window; the runtime never expands it automatically.
Increasing N cannot recover compacted-away history or messages received after this workflow started; stop and relaunch the workflow when updated instructions must enter its snapshot.
Narrow or reassign work that exceeds the supported scope, and preserve review-only assignments even under a broader request to fix things.
Use genuine existing answers instead of routinely asking the user to repeat an approval already present.
This self-check is advisory reasoning, adds no required verdict, hook, model call, approval authority, or launch gate, and cannot manufacture human consent.
